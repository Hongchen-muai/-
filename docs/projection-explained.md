# 从球到地图：读懂点、线和椭圆

## 先分清“照出来”和“算出来”

把地球投影想成光照在一个面上，是有用的入门比喻，但不能解释所有投影。

- **球面立体投影**：O 是真实的透视视点，位于投影中心的对跖点。直线经过球面点 P，与平面相交得到 M。
- **正射投影**：视点在无限远，射线相互平行，没有有限的公共光源点。
- **墨卡托、圆柱等面积、等距圆柱**：不能只靠一个光源得到。演示中的球心 O 只作几何参考。
- **圆锥三种、兰伯特等面积方位**：按相应公式得到位置；不虚构统一点光源。

## 圆柱中的 O、P、G、M

| 符号 | 含义 |
| --- | --- |
| O | 球心几何参考点，不是所选圆柱投影的真实光源 |
| P | 地球上的一个示例位置；画面会标出它的纬度 |
| G | 球心参考射线与圆柱的几何交点 |
| M | 所选投影公式给出的真正位置，与右侧地图对应 |

实线先呈现 O、P、G 的几何关系；随后橙色虚线和移动标记表示 G 到 M 的数学修正。这里是**对照解释**：实际制图可直接从 P 的经纬度计算 M，并不需要先制作一张球心透视地图。橙色线也不是折射或弯曲的光线。

圆柱或平面与球体相割时，射线可能先到辅助面再到球面，即 O—G—P（或 O—M—P）。不能为了符合直觉而强画成固定的先后顺序。

## 为什么出现两组圈

**蓝色是球面上的标准纬线，红色是它的投影。它们对应同一纬度，但不是同一个空间圆。** 标准线处的长度比例为 1，不要求两个圆的空间高度相同。

以截图中的正轴等距圆柱、标准纬度 60° 为例：

- 圆柱半径：`r = R cos 60° = 0.5R`。
- 球面纬线的直角坐标高度：`R sin 60° = 0.866R`。
- 投影保存的是有向经线弧长，所以映射高度为：`R × π/3 = 1.047R`。

红圈比蓝圈高约 `0.181R` 是正确结果，不是画偏了；南侧方向相反。强行把红圈移到蓝圈高度，会破坏等距条件。相切赤道等特殊情况下，两条对应线才会重合。

## 怎样理解双视图变形椭圆

球面上放置相同角半径的微小参考圆，用同一局部微分矩阵计算它们的一阶变形椭圆。三维与二维共用位置、形状和方向；两边任一开关都会同步。

- **等角**：展开正视时，椭圆应为圆，但不同位置的圆可以大小不同。
- **等面积**：不同位置的椭圆面积相同，形状可以变扁或拉长。
- **等距圆柱 / 圆锥**：沿经线方向的局部长度比例为 1，不保证任意方向或任意两点都等距。
- **正射**：越靠半球边缘，径向压缩越明显。

三维斜视、曲面弯曲和遮挡也会改变屏幕上的外观。判断投影性质应对照“平面结果”的正视图；不是要求从任何角度看三维曲面，圆都仍呈圆形。接缝或裁切边界附近的取样圆可能共同省略，避免跨边界连接。

这些是局部一阶变形图示，不是声称一个有限大小圆的精确投影永远是椭圆。角度和面积性质针对数学坐标；左右各自的显示缩放不改变这些性质。
