# 排版与入门导览验收

更新：2026-09-09。本轮只调整前端交互，未修改投影公式或三维引擎。

## 排版

- 桌面保留三维、共享参数、二维三列。图层开关集中在中栏参数下方，减少空白与跨栏查找。
- 原理说明改为下方横向双列，公式单独成行；窄屏按单列排列。
- 标题高度、按钮与长标签重新对齐，保留原来的浅色界面。
- 顶部投影抽屉默认收起，点击或悬浮展开，选择后收起，不改变三栏宽度。共五项，当前项更大更清晰，其他项随距离收窄淡化；最后一项为不可选的“其他待完善”。
- “常用投影”显示标签改为“任意投影”，内部模式及计算不变。

## 导览预期

1. 进入和刷新页面均不自动弹出导览；只通过右上角问号打开。
2. 依次解释球面与地图、蓝红线、O/P/G/M 与射线、变形椭圆、投影参数。周围区域淡化模糊，当前对象保持清晰。
3. “上一项”“下一项”、关闭按钮与 Escape 均可用；焦点限制在导览内。关闭后恢复原来的滚动位置和焦点。
4. 不再读取或写入自动提示偏好，也不显示“不再提示”复选框。
5. 导览不切换投影、不改变参数、不改变动画阶段，也不能透过聚焦区域误操作背景控件。

手机竖屏采用上方对象、下方说明；长文在说明区内滚动，底部操作保持可见。高度不足的横屏改用居中说明，避免正文和按钮被挤出屏幕。导览本身不强制开启被关闭的图层，字母与椭圆另有独立示意。

## 悬浮解释

参数、图例、O/P/G/M 以及重合标注支持上下文说明。鼠标停留约 0.8 秒后出现；按下鼠标立即取消提示，避免快速点击或拖动时被打断。支持键盘焦点，手机可点按字母与图例。Escape、移出或点击外部可关闭；点标注的弹窗避开画布中的相邻标注。
