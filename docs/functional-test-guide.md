# 功能测试速查

适用：当前九种投影的**球面教学模型**。左侧为三维，右侧为二维。

## 先记住三点

1. **二维会自动适屏**：整体等比例缩小会被自动放大回来。因此“地图外形没变”不一定是 bug；红线变化仍应可见。二维的 100% 是显示倍率，不是统一的制图比例尺。
2. **相机与投影参数独立**：先拖动三维到侧面，再调参数，角度和缩放应保持。只有主动切换演示阶段、重播或点击“适应视图”才重新取景。参数令模型超出视口时，可主动适应视图。
3. **交圈不总是真比例圈**：圆柱、圆锥红线是标准线；本模型的立体投影交圈也是局部真比例圈。兰伯特等面积方位、正射的非零交圈不是无变形圈。

## 共用参数

| 操作 | 理想效果 |
| --- | --- |
| 中央经线增大 / 减小 | 中央经线向东 / 向西移；地球轮廓和投影地图重新对应。例如设 110°，中国附近移到地图中央经线附近。观察相机不随之转回默认角度。 |
| 方位投影中心经度增大 / 减小 | 中心向东 / 向西移，所见半球与地图地物改变；中心点对应新的地理位置。 |
| 方位投影中心纬度增大 / 减小 | 中心向北 / 向南移；90° 为北极中心，-90° 为南极中心。三个子投影都必须重新计算地物。 |
| 圆锥投影原点纬度增大 / 减小 | 只改变纵坐标零点，不旋转地球，不改变包裹状态的圆锥和地图。展开图在三维世界中可整体下移 / 上移；二维自动居中后轮廓不动，原点小十字位置改变。原点在展示范围外时十字不显示。 |
| 圆柱正轴 / 横轴切换 | 球面投影轴转过 90°，地图重新计算，不是把平面地图简单旋转。横轴红线是轴向标准线，不是地理纬线。 |

## 九种投影的辅助面参数

下表“增大”指从 **0° 到 60°**，圆锥另行说明；减小则反向变化。每次只改变一个参数。

| 投影 | 左侧三维应发生什么 | 右侧二维应发生什么 |
| --- | --- | --- |
| 墨卡托 | 割线纬度增大，圆柱半径缩小；地图的包裹半径和高度都等比例缩小。球面两条蓝线远离赤道。 | **地物外形和大小基本不变**，因为适屏抵消了统一缩放；红线离赤道更远。原始 x、y 均缩至一半。 |
| 圆柱等面积 | 圆柱变细，映射高度增大，两条球面蓝线远离赤道。 | **必须变得更窄长**：原始 x 减半、y 加倍，宽高比变为原来的 1/4。0° 是兰伯特形式。 |
| 等距圆柱 | 圆柱变细，映射高度不变；球面蓝线远离赤道。 | **必须改变宽高比**：原始 x 减半、y 不变，宽高比变为原来的 1/2。仅正轴 0° 为方格网 Plate Carrée。 |
| 球面立体投影 | 交圈角距增大，平面向球心靠近，投影图整体缩小；红圈扩大。射线视点固定在中心的对跖点。 | **地物外形和大小基本不变**，因为适屏抵消统一缩放；红圈扩大。原始坐标缩至 3/4，等角性质不变，交圈局部长度比例为 1。 |
| 兰伯特等面积方位 | 平面向球心靠近，**投影图 x、y 尺寸不变**；交圈及其映射扩大。 | **地物必须不变**，只有红圈改变。这由等面积公式决定，不是漏联动。 |
| 正射 | 平面向球心靠近，**投影图 x、y 尺寸不变**；平行射线长短改变，红圈扩大。 | **地物必须不变**，只有红圈改变。这是平行投影的性质。 |
| 兰伯特等角圆锥 | 例如保持第二线 47°，第一线从 17° 调到 30°：第一条球面蓝线北移，圆锥及映射改变；另一条球面蓝线纬度仍为 47°。 | **地图扇形和地物分布应改变**；标准线仍为真比例，局部等角不变。 |
| 阿尔伯斯等面积圆锥 | 同上；两条标准线共同决定圆锥常数和径向映射。 | **地图形状应改变**，面积比例仍保持。不能要求所有地方一起等比例变大或变小。 |
| 等距圆锥 | 同上；沿经线的映射长度保持真实，纬线间的径向间距对应纬差。 | **地图形状应改变**，沿经线的长度比例仍为 1；不是任意两点都等距。 |

圆锥补充：在两条线都在北半球时，增大任一纬度会使 n 增大、展开扇区角度增大；减小则反向。在南半球应看 |n|，不能照搬北半球的方向结论。两线相等是相切形式；两线关于赤道对称时取圆柱极限，不应报错或变白。调第一 / 第二线时，另一条**球面**蓝线位置不变，但它的**平面**位置可以随整个投影改变。

横轴圆柱也遵守上述比例规律，但横、纵方向在最终北向恢复后互换；优先检查地物与轴向红线的对应，不按地理纬线判断。

## 显示与演示

| 功能 | 理想效果 |
| --- | --- |
| 辅助面 → 投影映射 → 平面结果 | 第一阶段有完整可见半球轮廓；第二阶段出现地图与连线；第三阶段球体和连线退出，图形与右侧同形，红线对应。 |
| 射线 / 映射连线 | 圆柱先显示 O—P—G 的球心几何参考，再以橙色虚线表示 G—M 数学修正；O 不是所选圆柱投影的真实光源。立体、正射保留真实透视 / 平行射线；圆锥和等面积方位仅画数学映射。相割时辅助面落点可能在球面点之前。 |
| 辅助投影面开关 | 只隐藏辅助面，不应擦掉地球轮廓，也不改变二维地图。 |
| 投影地图开关 | 只隐藏辅助面上的地图，不隐藏原始地球轮廓；不改变二维地图。 |
| 经纬网 / 红线开关 | 同步控制两侧对应图层，不改变投影公式。 |
| 视点 / 参考点开关 | 立体投影中是对跖点视点 O，圆柱中是球心几何参考 O；只隐藏标记，不改变投影。 |
| 变形椭圆开关 | 两侧同步。球面显示等大小微小参考圆，辅助面和展开结果显示共用雅可比矩阵计算的一阶椭圆。展开正视时：等角保持圆形，等面积保持面积。三维斜视的视觉压缩不是投影变形。 |
| 二维缩放增大 / 减小 | 右侧放大 / 缩小；不改变三维相机和数学参数。放大后超出边界被裁掉属于正常显示。 |
| 三维拖动 / 滚轮 | 只改变观察角度 / 缩放，不改变二维投影。 |
| 重播中改参数或切换投影 | 旧动画应停止，保留当前观察位置，完整显示更新后的当前阶段，不出现白球或延迟跳到旧投影。 |

蓝色区分球面参考线，红色区分投影对应线；空间位置不必重合。详见 [点、线和椭圆的解释](projection-explained.md)。

## 一分钟复测

1. 圆锥等面积设中央经线 -22°、原点 18°、两条标准线 17° / 75°。第一、二阶段均应看清欧洲、非洲等轮廓，无整条白色遮挡带。转到侧面再改 17° → 25°，相机不跳回。
2. 圆柱分别选三种性质，割线纬度 0° → 60°：墨卡托地物外形不变；另两种明显变窄长；三者红线都改变。
3. 方位三种分别将交圈角距 0° → 60°：地物外形不变、红圈扩大；只在立体投影中，三维辅助面上的地图整体缩小。

朝向大洋时陆地较少是正常的；判断缺图应选择非洲、欧亚大陆或美洲朝向，并打开经纬网。不要把视口外的内容、地球背面或大面积海洋当成丢失的轮廓。

数学依据：[PROJ 投影定义](https://proj.org/en/stable/operations/projections/index.html)。自动适屏属于本网站的显示策略，不是投影公式的一部分。
