# 投影正确性与验收记录

## 数学口径

- 采用单位球面公式，三维半径固定为 R = 5。辅助面 1.01 的偏移只服务于绘制，在展开终点归零，不进入投影比例条件。
- 三维与二维共用 D3 投影、旋转、球面裁切和经纬线数据；三维展开终点严格为 (Rx, Ry, 0)。SVG 的纵轴方向在渲染层翻转一次。
- 墨卡托采用 k0 = cos(phi_s)，纵坐标采用对数等距纬度，不使用球心透视的 tan(phi)。显示裁切 ±85°，不篡改极点附近的公式。
- 圆柱等面积和等距圆柱根据标准纬线参数命名；横轴模型使用球面旋转并恢复北向，不将正轴投影仅旋转一个显示角度冒充横轴。
- 球面立体投影的视点在对跖点，切平面径向距离为 2R tan(c/2)；移动平面后为 (R+d) tan(c/2)。D3 原始立体投影的尺度因子已校正。
- 兰伯特等面积方位采用 2R sin(c/2)，正射采用 R sin(c)。辅助平面位置不能任意缩放这两者的平面坐标。
- 圆锥使用 D3 的标准正反算与独立圆锥常数校验。相等标准纬线使用相切形式；南半球使用有符号 n；对称标准纬线使用正确的圆柱极限。
- 圆锥原点纬度仅改变纵坐标零点。辅助面的几何锚定独立于原点，不能借原点参数旋转球体或移动包裹形态。
- 红色标准线由真实比例条件确定；本项目球面立体投影在交圈上的局部长度比例为 1。兰伯特等面积方位、正射的非零交圈不是无变形圈，不能将方位投影统一视为同一种情况。
- 变形椭圆来自局部微分矩阵作用于等大的球面无穷小圆，没有分别限制长短轴。跨接缝的差分、背面点和裁切边界之外的点不参加绘制。

## 数值验收（2026-09-06）

- `npm test`：104,462 条数值断言通过。包含共享模型的球面正反算、D3 对照、旋转、截断边界、两侧展开坐标、标准线比例、等角的正交与等比例条件、等面积的雅可比行列式、等距的经线长度比例，以及近圆柱极限下的 Float32 属性精度。

- 地图显示缩放不参与比例性质验证；上述条件针对原始投影单位，不是经过适屏缩放后的像素尺寸。

当前球面参考线使用蓝色，投影对应线使用红色。等距圆柱 60° 的球面线高度是 0.866R，投影线高度是 1.047R，回归断言禁止将它们错误地强制重合。圆柱示例中 G 落在辅助圆柱上，并与 O、P 共线；G 到 M 沿同一母线作数学修正。

合法数值即时更新；空值可以继续编辑；越界值在失焦或回车提交时校正。实测中央经线 999° 校正为 180°、-60.5° 保持小数，显示缩放 140% 即时更新、999% 校正为 180%。各参数范围滑块均单独操作并核对共享状态。

## 使用边界

这是球面地图投影教学模型，不用于椭球测量、工程放样或 UTM 坐标转换。方位投影统一采用半球演示窗口，圆锥采用界面标明的区域纬度带；不是宣称其数学定义域只限于这些范围。相机透视方向、屏幕适配和显示缩放不改变原始投影。
