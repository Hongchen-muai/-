# 地图投影可视化展示平台 (Map Projection Visualizer)

> **本项目是一个基于 Vue 3 + Three.js + D3.js 构建的纯前端地理数学交互式教学可视化平台。**  
> 核心目标是将抽象的地图投影过程，通过流畅的 3D 几何展开动画与 2D 平面地图实时互动展示出来。

---

## 1. 快速启动 (Quick Start)

**环境要求**：Node.js 20.19+ 或 22.12+（与 Vite 8 的要求一致）。

```bash
# 1. 安装项目依赖
npm install

# 2. 启动前端开发服务器
npm run dev

# 3. 编译打包用于生产环境部署
npm run build

# 4. 投影数学与展开回归测试
npm test
```

## 2. 当前功能与技术重点

当前系统以 Vue 3 管理交互状态，Three.js 展示三维辅助投影面和展开动画，D3.js 绘制二维地图结果。`src/core/projectionModel.js` 统一球面旋转、投影公式、定义域裁切、标准线及展开坐标。两侧使用相同的 D3 地理数据流，而不是分别计算不同的投影。

### 2.1 操作流程
1. 顶部的投影抽屉默认收起，点击或悬浮后选择圆柱、方位、圆锥或平等地球；“其他待完善”为占位项。
2. 前三组选择等角、等面积或任意投影；平等地球仅提供等面积模式。
3. 使用三维底部阶段按钮或重新演示：辅助面、投影映射、平面结果。
4. 参数面板中的合法数值实时作用于两侧。每个投影族分别保留其辅助面参数，避免圆柱参数覆盖圆锥参数。
5. 入门导览仅通过右上角问号打开。参数、图例及 O/P/G/M 支持约 0.8 秒悬浮解释；快速点击不会触发解释。

### 2.2 标准线与红线
圆柱和圆锥的红线是由投影比例条件定义的标准线，沿标准纬线方向的长度比例为 1。横轴圆柱的红线属于旋转后的轴向坐标，不是地理纬线。辅助圆锥上的数学标准线不强称为球面几何交圈。

方位投影的红圈是辅助平面与球面的交圈及其映射，不能一般性地称为无变形圈。交圈角距为零时显示投影中心点。

具体而言，本项目的球面立体投影在交圈上的局部比例为 1；兰伯特等面积方位和正射的非零交圈则不是无变形圈。

### 2.3 观察与参数
三维拖动和滚轮只改变相机，不改变投影。二维缩放只改变显示倍率，不是制图比例尺。中央经线或方位投影中心通过参数面板设置；圆锥原点纬度只改变坐标零点，不旋转地球，也不改变包裹状态的辅助面。

### 2.4 现有十种投影
1. **圆柱**：墨卡托 / 圆柱等面积 / 等距圆柱。圆柱等面积仅在标准纬线为赤道时称兰伯特形式；正轴等距圆柱在标准纬线为赤道时称 Plate Carrée。
2. **方位**：球面立体投影 / 兰伯特等面积方位 / 正射。
3. **圆锥**：兰伯特等角圆锥 / 阿尔伯斯等面积圆锥 / 等距圆锥。
4. **平等地球**：Equal Earth 等面积伪圆柱投影。纬线平行、经线弯曲、两极为极线；仅调整中央经线，不套用物理割线参数。

所有公式均为球面模型，不是椭球生产坐标系或 UTM。墨卡托展示到轴向纬度 ±85°，不将极点强行压到边界；方位投影统一展示中心半球；圆锥采用页面标明的区域纬度范围。这些是演示裁切范围，不是对投影完整数学定义域的断言。

### 2.5 数据加载
世界地图数据从 `public/world-110m.json` 本地读取，避免演示环境依赖外部 CDN。

## 3. 项目目录结构架构说明

为了保证高可维护性，项目严格遵守**“数据、UI、算法引擎”**相分离的架构模式。

```text
map-projection-visualizer/
├── public/                 # 静态资源目录（图标、离线 JSON 地图、赞赏码）
├── src/                    # 核心源代码目录 
│   ├── App.vue             # 【全局总控司令塔】负责整个 UI 架构、状态同步。
│   ├── main.js             # Vue 应用启动入口。
│   ├── components/         # UI 视图组件。 
│   │   ├── Map2D.vue       # D3.js 驱动的 2D 互动地图，包括下方的输入框与双向绑定面板。
│   │   └── Scene3D.vue     # Vue 包装层，负责将底层的 3D WebGL 画布安全嵌入网页。
│   └── core/               # 核心算法与渲染引擎（与前端框架完全解耦）
│       ├── mapMath.js      # 投影配置、默认参数、比例条件和原始公式。
│       ├── projectionModel.js # 两侧共用的投影、旋转、裁切、标准线和展开模型。
│       ├── projectionTeaching.js # 各投影的公式与几何/数学构造说明。
│       ├── worldData.js    # 共用的本地地理数据加载与错误处理。
│       └── threeApp.js     # Three.js 场景、三维投影动画、WebGL 展开材质和 GSAP 动画序列。
├── package.json            # 项目依赖清单
└── README.md               # 项目协作文档
```

## 4. 核心机制：状态与双向联动通信

`App.vue` 是参数和 UI 状态的唯一来源，向两个渲染组件传递同一投影族、性质和参数。`Scene3D.vue` 只负责生命周期和回调桥接；`threeApp.js` 不导入 Vue。数学公式与裁切位于共享模型，D3 的正反算、地理裁切和自适应采样构成核心。

三维动画先将球面坐标迁移到公式定义的辅助面位置，再等距展开圆柱或圆锥。过渡帧只表示坐标迁移，等角、等面积性质针对完成后的数学映射。除球面立体投影与正射的真实透视构造外，连线不表示共同点光源。辅助平面移动对正射、兰伯特等面积方位的平面坐标没有影响；球面立体投影按实际透视距离统一缩放。

## 5. 验证

`npm test` 检查九种投影及横轴、南北半球、相切、圆柱极限、裁切、真比例标准线、原点不变性和展开终点。`scripts/test-proj-oracle.py` 可在安装 `pyproj` 的 Python 环境中运行，对命名地理地点使用独立 PROJ 引擎对照。

数学依据、验收范围和网页截图记录见 [验证记录](docs/verification.md)。

平等地球的公式、标准纬线、独立 PROJ 对照与新增功能验收见 [平等地球验证](docs/equal-earth-verification.md)。[公众号介绍与三张演示动图](docs/wechat/地图投影平台介绍.md) 可用于平台介绍。

逐参数的增大 / 减小预期、正常不变的情况与复测步骤见 [功能测试速查](docs/functional-test-guide.md)。调参保留三维相机，主动点击“适应视图”才重新取景；球面轮廓使用独立绘制顺序，示例点有 P、G、M 标注。

当前演示以蓝色区分球面标准线、红色区分投影对应线；圆柱以 O—P—G 几何参考和 G—M 数学修正解释非透视投影，不假装统一光源。三维和二维现共用变形椭圆的取样及微分矩阵，两侧开关同步。入门解释见 [从球到地图](docs/projection-explained.md)。
