# 地图投影可视化展示平台 (Map Projection Visualizer)

> **本项目是一个基于 Vue 3 + Three.js + D3.js 构建的纯前端地理数学交互式教学可视化平台。**  
> 核心目标是将抽象的地图投影过程，通过流畅的 3D 几何展开动画与 2D 平面地图实时互动展示出来。

---

## 1. 快速启动 (Quick Start)

**环境要求**：Node.js (建议 v16+ 环境)

```bash
# 1. 安装项目依赖
npm install

# 2. 启动前端开发服务器
npm run dev

# 3. 编译打包用于生产环境部署
npm run build
```

## 2. 当前功能与技术重点

当前系统以 Vue 3 管理交互状态，Three.js 展示三维承影面和展开动画，D3.js 绘制二维地图结果。投影参数、投影名称和默认标准线集中在 `src/core/mapMath.js`，用于减少 3D 与 2D 公式不一致的问题。

### 2.1 操作流程
1. 在左侧选择投影族：圆柱、方位或圆锥。
2. 选择投影性质：等角或等面积。
3. 使用场景底部的上一步/下一步观察三维过程：套合投影面、投影到承影面、展开为二维地图。
4. 展开后在二维参数面板调整投影中心、标准纬线或标准圈，并同步联动 3D 场景。

### 2.2 标准线与红线
红色线表示标准纬线或标准圈。该处局部比例尺为 1，线外变形按投影类型重新分布。

### 2.3 鼠标模式
1. **视角旋转**：只改变观察相机，不改变投影参数。
2. **旋转切割面**：改变投影中心/投影轴方向，用于观察斜轴投影效果。

### 2.4 支持的六种投影
1. **圆柱投影**：墨卡托投影 (Mercator) / 兰勃特等面积圆柱投影 (Lambert Cylindrical Equal-Area)
2. **方位投影**：平射方位投影 (Stereographic) / 兰勃特方位等面积投影 (Lambert Azimuthal Equal-Area)
3. **圆锥投影**：兰勃特等角圆锥投影 (Lambert Conformal Conic) / 阿尔伯斯等面积圆锥投影 (Albers Equal-Area Conic)

### 2.5 数据加载
世界地图数据从 `public/world-110m.json` 本地读取，避免演示环境依赖外部 CDN。

## 3. 项目目录结构架构说明

为了保证高可维护性，项目严格遵守**“数据、UI、算法引擎”**相分离的架构模式。

```text
map-projection-visualizer/
├── public/                 # 静态资源目录（图标、离线 JSON 地图、赞赏码）
├── src/                    # 核心源代码目录 
│   ├── App.vue             # 【全局总控司令塔】负责整个 UI 架构、状态同步。
│   ├── main.js             # Vue 应用启动入口。
│   ├── components/         # UI 视图组件。 
│   │   ├── Map2D.vue       # D3.js 驱动的 2D 互动地图，包括下方的输入框与双向绑定面板。
│   │   └── Scene3D.vue     # Vue 包装层，负责将底层的 3D WebGL 画布安全嵌入网页。
│   └── core/               # 核心算法与渲染引擎（与前端框架完全解耦）
│       ├── mapMath.js      # 共享投影配置、默认参数和核心投影公式。
│       └── threeApp.js     # Three.js 场景、三维投影动画、WebGL 展开材质和 GSAP 动画序列。
├── package.json            # 项目依赖清单
└── README.md               # 项目协作文档
```

## 4. 核心机制：状态与双向联动通信

本项目的亮点在于 **3D 物理模型** 与 **2D 地图投影** 的实时互动。为防止数据冲突，系统维护唯一的全局状态，链路如下：

*   **唯一真理来源**：`App.vue` 维护投影族、投影性质、标准线参数和 `globeRotation`。
*   **通信方向**：
    1. **3D 驱动 2D**：用户鼠标拖拽 3D 场景 -> `threeApp.js` 触发矩阵变换求出新的经纬度 -> 调用 `onRotationChange` 回调 -> `App.vue` 更新状态 -> `Map2D.vue` 收到 Props 变动 -> D3 旋转重绘平面图。
    2. **2D 驱动 3D**：用户拖动 `Map2D.vue` 下方滑块 -> `Map2D.vue` 发出 `emit` 事件 -> `App.vue` 更新数据 -> 直接调用 `setGlobeRotation()` API -> 3D 引擎使用四元数矩阵强制更新渲染。
